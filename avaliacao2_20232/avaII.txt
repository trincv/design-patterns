public class adapterAes256Criptography extends CriptographedMessage {

    private AES256 criptography;

    public adapterAes256Criptography(Request message, AES256 criptography) {
        super(request);
        this.criptography = criptography;

        this.criptography.init();
    }

    @Override
    public byte[] getContent() throws securityException { 

        byte[] criptographedMessage = message.getContent();

        criptographedMessage = this.criptography.doFinal(criptographedMessage);

        return criptographedMessage;
    }

}

Nesse caso utilizaríamos o adapter como mecanismo de possibilitar a interação do sistema com essa classe de criptografia externa, assim a classe adapter desenvolvida
    age tanto como decorator quanto como adapter. Adaptando métodos da classe externa para que possam ser utilizados de acordo com a lógica e sintaxe do
    middleware sendo desenvolvido. Essa classe substituiria a que criei na primeira questão, já que fariam a mesma coisa.
